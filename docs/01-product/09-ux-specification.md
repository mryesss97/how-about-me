## 1. Information architecture & routes

```text
/login                          Public
/                               Landing (signed in, full screen, no sidebar; default after login, #262)
/(app)                          Authenticated shell (sidebar + header)
├─ /overview                    Dashboard (Explore from the landing)
├─ /mentions                    Mentions Explorer
│  └─ /mentions/[id]            Mention detail (route; also opens as slide-out from list)
├─ /listening-queries           Query table + create/edit drawer
├─ /reviews                     Review queue (P1)
├─ /system-status               Threads / collector / analyzer / DB + Sync jobs tab + Audit tab (admin)
└─ /settings
   ├─ /settings/project         Name, timezone, toggles
   ├─ /settings/members         Members & roles (admin)
   ├─ /settings/integrations    Threads connection (admin write, analyst read; hidden from viewer)
   └─ /settings/analysis        Thresholds & versions (P1)
```

Sidebar (Untitled UI `sidebar-simple`, signboard style #274 — sky enamel sign, white logo plate, condensed caps labels, current item as a white plate): logo links to `/` (landing, #262) · Tổng quan · Bài nhắc · Truy vấn theo dõi · Cần xem lại (P1) · Trạng thái hệ thống · Cài đặt. Footer: account card (e-mail, role plate Quản trị / Phân tích / Chỉ xem, Đăng xuất). Current project (#348): right under the logo, every role sees "Dự án" + the project name; with ≥ 2 projects it is a select with the visible label "Dự án" (FR-036, TC-PROJ-012). Switching keeps the route and drops its query string (filters are project-scoped); `/mentions/[id]` goes to `/mentions` and `/terms/[term]` to `/overview`. Current item (#325, BR-017): the item whose path is the longest segment-aligned prefix of the URL — Cài đặt for every `/settings/*` tab, Bài nhắc for `/mentions/[id]`; exactly one `aria-current="page"`, none on unknown paths. Carried filters (#331): while on Overview, Mentions (incl. `/mentions/[id]`) or a phrase page, the Tổng quan and Bài nhắc items keep `preset/from/to/tz/queryIds/relevance` from the current URL; every other key resets; elsewhere the hrefs are bare. Not a saved view. The first tab stop is a skip link "Bỏ qua tới nội dung chính" to `<main id="main-content">`. Every page opens with a page fascia (white enamel board, navy keyline, title in sign lettering). Copy moves to Vietnamese screen by screen (#274, #275, #277–#281). **Nav plates (#345):** "Cần xem lại" carries a small white plate with the unreviewed count (`counts.all` of `GET …/reviews?status=unreviewed&limit=1&count=true`, same as the "Tất cả" tab) for admin/analyst only — viewers neither see it nor fetch it; hidden when the count timed out (never a fake "0", BR-032) or is 0; Vietnamese thousands dot, no cap; drops optimistically on mark-reviewed. "Trạng thái hệ thống" carries a dot **+ word** (BR-017): "Lỗi" (red) when the shell strip shows an error, "Chậm" (amber) when collector is `degraded` or analysis ≠ `healthy`, "Sắp hết hạn" (amber, admin only) for a token within 7 days; nothing when healthy. Plates invert (navy) on the current item.

## 2. Global patterns

### 2.1 Filter bar (shared by Overview & Mentions)

- Sticky under the header; since #275 a white enamel panel with a 2px navy rule, controls stay Untitled/Inter. Labels are Vietnamese (#275): Khoảng thời gian (1 giờ · 24 giờ · 7 ngày · 30 ngày · Chọn ngày) · Múi giờ · Truy vấn · Mức liên quan (Liên quan / Chưa chắc / Không liên quan) · Cảm xúc · An toàn · Ý định · Chủ đề · Ngôn ngữ · Trạng thái phân tích · "So sánh với kỳ trước" · "Đặt lại". Enum values in the URL stay English.
- Order: **Time range** (preset segmented control + custom date-range picker + timezone select) · **Queries** (multi-select with `#` rendering for tags) · **Relevance** (default `Relevant`; chips `Relevant`, `Uncertain`, `Irrelevant`) · **Sentiment** · **Safety** · **Intent** · **Topic** · **Language** · **Analysis status** · "Compare with previous period" toggle (Overview only) · "Reset".
- **"Sao chép liên kết" (#349, FR-142/FR-130)** on Overview and phrase detail: last item of the desktop row (`ml-auto`); icon-only (44 px, accessible name kept) in the mobile summary strip before "Bộ lọc". Copies the **absolute** URL of the current page with the range resolved at click time and pinned as `preset=custom&from&to` (other filters, `q`, `sort`, `term`, `compare` kept), so the recipient sees the same post set. Toast "Đã sao chép liên kết · 12/10–19/10"; clipboard failure → "Không sao chép được. Hãy sao chép từ thanh địa chỉ.". Not saved views.
- Default time preset is **7d**. The timezone select lists all IANA zones with `Asia/Ho_Chi_Minh` and `UTC` pinned first. Custom ranges over 366 days show an inline error and are not applied.
- Changing the timezone keeps a custom range's **calendar dates** (#240): the selected days are re-read as `[from 00:00, to+1 00:00)` in the new timezone (e.g. 1–7 Oct stays 1–7 Oct). Only ranges whose ends are both 00:00 in the old timezone are re-zoned; exact-instant ranges (e.g. hour-bucket drill-down, FR-142) keep their instants. Relative presets (1h/24h/7d/30d) only change `tz`. `tz`/`from`/`to` update in one URL change.
- All filters sync to the URL query string (`nuqs`). Changing a filter refetches all widgets.
- Applied filters show as removable chips under the bar.
- **Compact layout (#332).** From `lg` (1024 px) the bar is **one row** (wraps only when it does not fit, e.g. 1024–1279 px), order unchanged: presets · date-range button · Truy vấn · Mức liên quan · **"Bộ lọc khác (n)"** · compare (Overview) · "Đặt lại". The date-range button always shows the effective dates (`12/10 – 19/10`, hours for 1h/24h, `· GMT±x` only when tz ≠ default); picking days switches to custom. **Mức liên quan** is a multi-select; an empty selection or "Bỏ chọn" falls back to `relevant` (BR-016). Accessibility (#385): every multi-select trigger is named label + value ("Truy vấn Tất cả"), in the row, the "Bộ lọc khác" popover and the mobile sheet; the date-range trigger is named in Vietnamese, never "Calendar". **Truy vấn** is hidden when the project has no queries. **"Đặt lại"** appears only when a filter differs from the defaults (incl. compare; `q`/sort belong to the Mentions toolbar).
- **"Bộ lọc khác (n)"** is a popover (2-column grid, applied live) with Cảm xúc · An toàn · Ý định · Chủ đề · Ngôn ngữ · Trạng thái phân tích · Múi giờ (BR-017: sentiment and safety stay separate). `n` = number of selected values in those six filters + 1 when tz ≠ default, so it matches the chips.
- **Below `lg`** the bar is one 48 px sticky summary strip (`top-14`, under the mobile header): `{preset} · {dates} · {n} bộ lọc` (preset dropped for custom, count dropped at 0; `n` counts every non-default filter except time) and a 44 px "Bộ lọc" plaque that opens a bottom sheet (max 85 dvh) with every filter stacked, the chips, and a footer "Đặt lại" / "Xong". Filters apply live; closing returns focus to the plaque. Chips show only inside the sheet.
- The bar is layered at `z-30`: above card content (KPI stretched links), below the mobile header (`z-40`) and modals (`z-50`).
- **Queries** options are the project's listening queries (FR-051), loaded by the filter bar itself (#329): active first, then soft-deleted ones marked "Đã xoá" so old drill-down links still show a name. Tags render as `#name` (no double `#`) in the select, the chips and the "Tỷ trọng từ khoá" chart.
- Multi-select copy is Vietnamese (#329): search "Tìm…", empty "Không có kết quả" / "Thử từ khoá khác.", footer "Bỏ chọn" / "Chọn tất cả"; trigger shows "Tất cả" (none), the value label (one) or "N đã chọn" (several). The keyword-share overlap note (FR-147) is Vietnamese too.

Guard on last admin: the sole admin's role select and Remove are disabled as a hint, with the visible reason "Quản trị viên duy nhất — không thể đổi vai trò hay xoá." under the name (linked via `aria-describedby`, no tooltip); a `409 LAST_ADMIN` reverts the role select and shows an error. Under `sm` the table becomes a stacked list (name/email → full-width role select → "Thêm lúc …" small print with Remove right-aligned, 44px).

Analyst sees a read-only card without controls; Viewer does not see the tab (deep link → Forbidden). ### 3.8 Reviews (`/reviews`) — P1

Queue of `uncertain`, low-confidence, failed items; tabs by reason; row → detail with override form (field, value, reason); "Mark reviewed".

Built in #219 (`apps/web/src/features/reviews`):

- **Signboard (#278):** tabs are plaques (`.plaque-button`, selected inverts to navy); tabs + toolbar sit in a white enamel panel with a 2px navy rule; the table sits in an `.operate-board` and scrolls horizontally inside it (390px never scrolls the page). Table, controls and helper text stay Inter. Copy is Vietnamese; enum values in the URL stay English.
- **Tabs** Tất cả · Chưa chắc · Độ tin cậy thấp · Phân tích lỗi, each with a count (`Tất cả · 1.234`) from page 1 `counts`. When the API omits `counts` (count timed out) the counts are hidden — never shown as 0 (BR-032).
- **URL state:** `?reason=uncertain|low_confidence|failed` (missing/invalid → All), `?status=reviewed` (toggle "Hiện mục đã xem lại"; default unreviewed), `?item=<postId>` (slide-out). Tabs and the toggle replace history; opening a row pushes, so Back closes the slide-out. Changing tab/status clears the selection.
- **Table:** post (user, time with tz tooltip, 2-line text, override icon "Có ghi đè"), reasons, relevance, sentiment, confidence (`%` + band; a band, not a probability — BR-020), analysis status (+ Vietnamese error label when failed, raw code in the tooltip; relevance/sentiment of a failed item are prefixed "Lần trước:", #338), and "Reviewed by" when Show reviewed is on. "Tải thêm" (plaque) paginates (25 / page). Confidence renders vi-VN (`42,0%`), band as Thấp / Trung bình / Cao. Column headers: Bài nhắc, Lý do, Mức liên quan, Cảm xúc, Độ tin cậy, Trạng thái, Người xem lại.
- **Mark reviewed (admin, analyst):** checkboxes; no idle "(0)" button — selecting ≥ 1 item shows a sticky **selection bar** at the bottom of the list (#339): "N mục đã chọn · Bỏ chọn" left, primary "Đánh dấu đã xem lại (N)" right; Esc clears the selection while the slide-out is closed; changing tab/status clears it too. Select-all and manual selection are capped at 50 (`MARK_REVIEWED_MAX`, helper "Tối đa 50 mục mỗi lần" inside the bar). Role-dependent controls render only after hydration (no SSR mismatch). Success toast "Đã đánh dấu N mục đã xem lại" (+ "(bỏ qua M)"). Rows disappear optimistically and come back with a toast "Không thể đánh dấu đã xem lại" (incl. "Mã yêu cầu") on error. Not offered under Show reviewed; no "Unmark" in v1. A new analysis run reopens an item (BR-040).
- **Keyboard (#339):** table rows — ↑/↓ move focus, Space selects, Enter opens. Slide-out — J next, K previous (ignored while typing or with a modifier; ↑/↓ stay for scrolling the panel), Esc closes. Hint "J/K: chuyển mục · Esc: đóng" under the title from `md`.
- **Slide-out (#339):** title "Chi tiết bài nhắc" + `‹ n / N ›` (N = loaded items, "+" while more pages exist; never the tab count). Prev/next **replace** `?item` (Back still closes the panel); › on the last loaded item loads the next page. The item's reason plates (+ confidence % for "Độ tin cậy thấp") sit under the title. Footer (sticky, all sizes): primary **"Đánh dấu đã xem lại · tiếp"** — marks that one item (BR-040) and opens the next; on the last item it reads "Đánh dấu đã xem lại" and closes. On error the item stays and a toast shows. Focus moves to the heading of the new item. Navigation is available to every role; marking only to admin/analyst. "Mở trang đầy đủ" → `/mentions/:id?back=/reviews?<tab filters>` so the full page shows "Về Cần xem lại" (#331). The override dialog has a checkbox "Đánh dấu đã xem lại sau khi lưu" (checked by default) → after saving it runs the same mark-and-next. The detail body (MentionDetail, override form) is restyled with Mentions (#277). **Deep link outside the loaded pages (#390):** the queue loads further pages (max 4 × 25 = 100 rows) until it finds `?item`; if still absent, the slide-out falls back to the post's own `review` (from mention detail, BR-040): reason plates from `review.reasons` (no confidence %), `‹ – / N ›` shown but disabled, muted hint "Mục này nằm ngoài danh sách đang tải", and — for admin/analyst when `review.status = unreviewed` — "Đánh dấu đã xem lại" (closes after marking) plus the override checkbox. The one-tap "Liên quan / Không liên quan" decision strip for "Chưa chắc" items is **not built** (needs owner decision).
- **Mobile (< md, #339):** rows become cards (user · time, 3-line text, reasons + verdicts + confidence in one wrapping line), checkbox and tab targets ≥ 44 px, "Chọn tất cả" above the cards. Slide-out header stays on one line: "Mở trang đầy đủ" is a 44 px icon button, nav moves to a second row; the primary action stays visible in the footer.
- **Viewer:** read-only — no checkboxes, no Mark reviewed, no override form.
- **Empty:** "Không có mục nào cần xem lại" / "Đã xem hết." (unreviewed) / "Chưa có mục nào đã xem lại" (reviewed).

## 5. Copy guidelines

**Từ vựng giao diện (#344).** One concept, one word on every screen. Codes stay in the API/URL; the UI shows the word.

| Khái niệm                                                          | Dùng                                                                                                 | Không dùng                                                   |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| Mention (post)                                                     | Bài nhắc                                                                                             | bài viết, đề cập                                             |
| Backfill                                                           | Lấy dữ liệu cũ (nút "Bắt đầu lấy dữ liệu")                                                           | quét bù, backfill                                            |
| Job / analysis `failed`                                            | Lỗi / Phân tích lỗi                                                                                  | thất bại                                                     |
| Failed user action (toast)                                         | "Không <động từ> được …" (e.g. "Không xuất được CSV.")                                               | "… thất bại"                                                 |
| Analyst override                                                   | Ghi đè / Thu hồi ghi đè / Có ghi đè                                                                  | chỉnh sửa nhãn, đã chỉnh sửa                                 |
| `RECENT` / `TOP`                                                   | Thứ tự lấy: Mới nhất trước / Nổi bật trước                                                           | RECENT, TOP, Gần đây, Kiểu tìm                               |
| `KEYWORD`/`TAG`, `keyword`/`topic_tag`                             | Từ khoá / Chủ đề                                                                                     | KEYWORD, TAG, topic tag                                      |
| Job not tied to a query                                            | Tất cả truy vấn                                                                                      | Toàn cục                                                     |
| Technical codes (cursor, migration, effective version, error code) | only in a `title` or with the suffix "(kỹ thuật)"                                                    | as a primary label                                           |
| Load error (API / network, #392)                                   | Vietnamese sentence from `lib/semantics/api-errors.ts`; code + requestId only in the small mono line | the API's English `message`, "Failed to fetch", `statusText` |

Shared maps live in `apps/web/src/lib/semantics/labels.ts` (`jobStatusLabelVi`, `jobTriggerLabelVi`, `searchTypeLabelVi`, `searchModeLabelVi`, `queryTypeLabelVi`); audit metadata values for these keys are translated too.

- Plain, factual, no blame ("Latest Threads sync failed" not "Something went wrong").
- Numbers use thousands separators; percentages 1 decimal; times relative (< 24 h) + absolute on hover.
- Timezone label shown next to time-range picker ("GMT+7 · Asia/Ho_Chi_Minh").
