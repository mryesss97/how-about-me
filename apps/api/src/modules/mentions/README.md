# mentions module

Implemented by the backlog tasks listed in [docs/03-delivery/02-work-breakdown.md](../../../../../docs/03-delivery/02-work-breakdown.md) (search for `mentions`).
Design: see docs/02-architecture/02-backend-design.md §3 and the related pipeline/API docs. Follow conventions in docs/06-engineering/03-coding-conventions.md §2.

## Implemented

- `POST /api/v1/projects/:projectId/mentions/:mentionId/reanalyze` (T-076, FR-115) — admin; analyst when `allowAnalystReanalyze`. 202 `{ runId, status: "pending" }`, 409 `ANALYSIS_ALREADY_PENDING` when the post has any `pending|processing` run, audit `analysis.reanalyze_requested`.
- `GET /api/v1/projects/:projectId/mentions` (T-095, FR-150/152/153/161) — all roles. Base set from `analytics-filters.buildBaseSetCte` (drill-down equivalence); sort specs + keyset predicate + search in `mentions-query.ts` (5 sorts, `post_id` tie-breaker, NOT NULL sentinels); cursor `encodeSortCursor` bound to the sort (timestamp keys as UTC µs `YYYY-MM-DDTHH:MI:SS.uuuuuuZ`, int/numeric as SQL text; `decodeMentionCursor` validates each key against its cast → 400, #195); `q` → FTS `websearch_to_tsquery('simple')`, ILIKE for < 3 chars or no letters/digits; `count=true` exact COUNT under `statement_timeout` 1500 ms (omitted on timeout). Projection in `mentions.mapper.ts`; matches/intents/topics/error codes hydrated in 4 batch queries; intents/topics come from `effective_post_intents|topics` keyed by `post_id` (override > AI, BR-025, T-142). Detail adds `overrides[]` (full history incl. revoked) via `ReviewsModule`'s `OverridesRepository.listForPost`.
- `GET /api/v1/projects/:projectId/mentions/:mentionId` (T-096, FR-154) — all roles. `findDetail` (one raw query: post + `effective_post_analysis` + current `post_analyses` + its run, no base-set filter) + reused `hydrate` + `listRuns` (50 newest, BR-003). `toMentionDetail` recomputes `safetyTriggered` via `mapSafetyLevel` (policy v1). 404 cross-project.
- `POST /api/v1/projects/:projectId/mentions/reanalyze` (T-145, FR-196) — admin only. List filters + `dryRun` → 200 `{ matched, enqueued, cap }`; `resolveFilterScope` shared with the list, `countMatched` (exact), `selectBulkCandidates` (≤ `ANALYSIS_BULK_MAX`, sort order, skips open runs / BR-024 duplicates) → `AnalysisService.enqueueMany(trigger=bulk)`; `BulkReanalyzeThrottle` → 429 + `Retry-After`; audit `analysis.bulk_reanalyze_requested`.
