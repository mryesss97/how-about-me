# features/reviews — Review queue (UX §3.8, FR-195, #219)

| File                                 | Purpose                                                                                                                                                                                                                                                        |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `api.ts`                             | `useReviewQueue(pid, { reason, status })` (infinite, `limit=25`, `count=true` on page 1, rejected cursor → reset). `useMarkReviewed(pid)` — optimistic removal from unreviewed caches (`removeFromQueue`), rollback + toast on error. `canMarkReviewed(role)`. |
| `use-review-params.ts`               | URL state: `?reason` (invalid → All), `?status=reviewed`, `?item` (slide-out).                                                                                                                                                                                 |
| `review-tabs.tsx`                    | All / Uncertain / Low confidence / Failed with count badges (hidden when `counts` is absent).                                                                                                                                                                  |
| `review-table.tsx`, `review-row.tsx` | Rows, multi-select capped at `MARK_REVIEWED_MAX` (50), load more, empty/error/skeleton.                                                                                                                                                                        |
| `review-detail-slideout.tsx`         | Shared `DetailSlideout` frame + "Mark reviewed"; body (MentionDetail) injected via `renderDetail` by the route (#233).                                                                                                                                         |
| `reviews-view.tsx`                   | Wires it together. Viewer: read-only (no checkboxes, no Mark reviewed).                                                                                                                                                                                        |
