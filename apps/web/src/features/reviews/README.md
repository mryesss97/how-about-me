# features/reviews — Review queue (UX §3.8, FR-195, #219)

| File                                 | Purpose                                                                                                                                                                                                                                                        |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `api.ts`                             | `useReviewQueue(pid, { reason, status })` (infinite, `limit=25`, `count=true` on page 1, rejected cursor → reset). `useMarkReviewed(pid)` — optimistic removal from unreviewed caches (`removeFromQueue`), rollback + toast on error. `canMarkReviewed(role)`. |
| `use-review-params.ts`               | URL state: `?reason` (invalid → All), `?status=reviewed`, `?item` (slide-out; open = push, `moveToItem` = replace, #339).                                                                                                                                      |
| `review-tabs.tsx`                    | Plaque tabs (#278) Tất cả / Chưa chắc / Độ tin cậy thấp / Phân tích lỗi with counts (hidden when `counts` is absent).                                                                                                                                          |
| `review-table.tsx`, `review-row.tsx` | Table from `md` + cards below (both rendered), multi-select capped at `MARK_REVIEWED_MAX` (50), ↑/↓ / Space / Enter (`use-roving-rows.ts`), load more, empty/error/skeleton.                                                                                   |
| `review-card.tsx`                    | Mobile card (< `md`, #339), 44px checkbox.                                                                                                                                                                                                                     |
| `review-cells.tsx`                   | `ReasonBadges`, `ConfidenceCell`, `BAND_LABEL` shared by row, card and slide-out.                                                                                                                                                                              |
| `selection-bar.tsx`                  | Sticky bar while ≥ 1 item is selected: count, "Bỏ chọn", cap helper, "Đánh dấu đã xem lại (N)" (#339).                                                                                                                                                         |
| `queue-nav.ts`, `use-queue-nav.ts`   | Prev/next over loaded items with the `lastIndex` fallback when the open item left the list; "n / N(+)" label; loads the next page (#339).                                                                                                                      |
| `review-detail-slideout.tsx`         | Shared `DetailSlideout` frame with nav, reason plates and footer "Đánh dấu đã xem lại · tiếp" (mark-and-next); body (MentionDetail) injected via `renderDetail(postId, ctx)` by the route (#233), `ctx.onOverrideSaved` for "mark after saving".               |
| `reviews-view.tsx`                   | Wires it together. Viewer: read-only (no checkboxes, no Mark reviewed). Role-dependent UI gated by `useHydrated()`.                                                                                                                                            |
