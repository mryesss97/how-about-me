## `detail/` — Mention detail (UX §3.4, T-104)

- `api.ts` — `useMentionDetail` (key `qk.mention`, polls 5 s while pending/processing), `useReanalyze` (POST `…/reanalyze`, optimistic `pending`, 409 `ANALYSIS_ALREADY_PENDING` → info toast), `canReanalyze(role, settings)` (admin, or analyst when `allowAnalystReanalyze`; UX only, BR-033).
- `mention-detail.tsx` — container shared by page and slide-out: loading / 404 / error, status banner, operations toolbar, Original + Analysis columns.
- `original-panel.tsx` + `linkify.ts` — plain text with https links only (`noopener noreferrer`, FR-157/158), media, quote/repost, matched queries (excluded ones labelled "excluded"), first/last seen, revision.
- `analysis-tabs.tsx` → `analysis-current.tsx` (badges, safety scores table, versions) and `analysis-history.tsx` (runs; no tokens per run in the contract).
- `key-phrases.tsx` (#250) — "Key phrases" row on _Current_: verbatim chips linking to `phraseMentionsHref(p)`; v1 text / dash. The chip URL has no `item`, so the slide-out closes on soft navigation to `/mentions` (#326).
- `status-banner.tsx` — pending/processing info, failed + error code + Retry (admin), stale warning. Retry uses `reanalyze` until `analysis-runs/:id/retry` exists.
- `operations-toolbar.tsx`, `use-copy.ts` — Re-analyze with confirm, copy post ID / permalink (toast), Open on Threads. UI copy is Vietnamese since #277 (Phân tích lại, Sao chép ID bài, …).
- Overrides (T-143, FR-191..194, BR-025): `api.ts` `canOverride(role)` (admin, analyst; UX only, FR-015), `useCreateOverride` / `useRevokeOverride` (refetch detail, mention list and analytics; 409 `OVERRIDE_CONFLICT` → info toast + refetch). `override-form.tsx` — dialog opened from the toolbar (field, value, required reason). `overrides.ts` — active override per field, `unknown` value narrowing, tooltip text. `value-source.tsx` — AI / Analyst badge, struck-through AI value at override time, Revoke with confirm. `override-history.tsx` — "Analyst overrides" table on the History tab (incl. revoked).
- `mention-detail-slideout.tsx` — rendered by `mentions-view.tsx` when `?item=<uuid>` is set (`use-mention-item.ts`, #326); the list stays mounted. Esc/close → `router.back()` when the view pushed the entry, else `replace` without `item`; focus returns to the row link. "Open full page" is a `next/link` to `/mentions/:id?<filters>`. Rows are a real stretched `<Link>` to the full page: plain click opens the slide-out, cmd/ctrl/shift/middle-click opens a new tab.

- `export-button.tsx` — `canExport(role, settings)` (UX only, BR-033), `useExportMentions` (`apiDownload` of `…/mentions/export.csv` with the pinned list params, saves the blob), `ExportButton` in the toolbar `actions` slot; toasts for 413/429/403 (T-147). The view renders it only after hydration (`useHydrated`, `src/hooks/use-hydrated.ts`): `/me` may already be cached when the Suspense boundary hydrates, so rendering it during hydration would mismatch the server HTML.
- `bulk-reanalyze-dialog.tsx` — `canBulkReanalyze(role)` (admin only, UX), `BulkReanalyzeButton` (toolbar `actions`, snapshots the pinned params on open) and `BulkReanalyzeDialog` (dry-run preview → Confirm, 0-matched / over-cap / 429 / 403 states; T-146, FR-196). Hook `useBulkReanalyze` in `api.ts`; rate-limit helpers in `src/lib/api/rate-limit.ts`.

Not here yet: `reviewStatus` filter (Reviews, P1).
